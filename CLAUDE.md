# SceneDrive Egypt — site

Next.js 16 (App Router, TS, CSS Modules, no Tailwind). Static, no backend. Booking = WhatsApp deep links.

- Design rules: `DESIGN.md` (tokens, type, motion, voice). Read before touching UI.
- Data: `src/data/{site,fleet,productions}.ts`. Call-sheet cart: `src/lib/callsheet.ts`.
- Sections: `src/components/<Name>/<Name>.tsx` + module css. Shared UI in `src/components/ui`. Section formerly CrashUnit is `Scenes` (id `scenes`).
- i18n: `src/i18n/{en,ar}.ts` dictionaries, `useT()` in client components, `{locale, t}` props for server sections, routes `/` and `/ar` via `src/app/[locale]`. Copy rules in DESIGN.md are binding (no crash wording, no counts, no Arabic in English).
- Media: `public/media/{v,loop,p,t,seq}` generated by `raw/pipeline.py` + `raw/pipeline_yt.py` from `raw/media` (Instagram dump, git-ignored). Validate refs: `python raw/validate_media.py`.
- Hero = `src/components/Hero`: sticky stage in a 520vh track, GSAP ScrollTrigger progress → beat cuts (looping muted videos), canvas scrubs `seq/h2_roll` frames on beat 4.
- ffmpeg binary: imageio-ffmpeg (`python -c "import imageio_ffmpeg as f;print(f.get_ffmpeg_exe())"`). No system ffmpeg.
- Commands: `npm run dev`, `npm run build`, `npx tsc --noEmit`, `npx eslint src`.
